# OpenSpec — настройка (слой намерения)

Spec-driven development для AI-агента. CLI-пакет: `@fission-ai/openspec`
(нужен Node.js 20.19+; в этом окружении Node 22 — ок).

## Инициализация (запустить в терминале, из корня репо)

```bash
# без глобальной установки, через npx:
npx -y @fission-ai/openspec@latest init . --tools cursor

# либо глобально:
npm install -g @fission-ai/openspec@latest
openspec init
```

`--tools` можно задать списком: `cursor,claude,codex,gemini,github-copilot` или `all`.
Отдельного профиля **GigaCode**, скорее всего, нет — но артефакты OpenSpec это
обычный markdown, который читает любой агент. Уточни у организаторов, какой профиль
ближе к GigaCode; если будет Cursor — интеграция родная.

После `init` появится папка `openspec/` со структурой спек и инструкциями для агента.

## Рабочий цикл (слэш-команды — в чате агента, НЕ в терминале)

```text
/opsx:explore                 # (опц.) обдумать идею до плана
/opsx:propose add-feature-x   # агент рисует план-спеку, ты ревьюишь
/opsx:apply                   # агент реализует по спеке
/opsx:archive                 # спека уходит в источник правды
```

## Полезные терминальные команды

```bash
openspec list               # активные изменения
openspec show <change>      # детали изменения
openspec validate <change>  # проверка формата спеки
openspec view               # интерактивный дашборд
```

## Зачем это для оптимальных запросов

Агент строит по зафиксированной спеке, а не переугадывает намерение на каждом шаге —
меньше итераций и меньше «уверенно сделал не то».

> Примечание: `init` намеренно не запущен автоматически (режим «только файлы»).
> Запусти команду выше, когда будешь готов.
