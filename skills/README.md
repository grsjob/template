# Skills

Каждый скилл — отдельная папка с файлом `SKILL.md` (открытый стандарт Agent Skills:
YAML-frontmatter `name` + `description`, дальше markdown-инструкции).

| Папка | Кейс |
|---|---|
| `_template/` | Пустой базовый шаблон — копируй под свой скилл |
| `analytics-requirements/` | Аналитика: «Требования из встречи» |
| `tech-debt-detector/` | Разработка: «Детектор техдолга» |
| `smart-regression/` | Тестирование: «Смарт-регрессия» |

## Как создать свой скилл

1. Скопируй `_template/` в `skills/<имя-в-kebab-case>/`.
2. Имя папки = поле `name` во frontmatter.
3. В `description` — что делает и КОГДА применять (это триггер для агента).
4. Опиши алгоритм, формат выхода и чек-лист самопроверки.
